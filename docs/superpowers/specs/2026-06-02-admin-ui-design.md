# 管理端 UI 设计

日期：2026-06-02

## 目标

本文档定义个人 AI 形象顾问 Agent 第一版 `admin` 管理端的 UI 设计。

管理端服务于运营配置、风格库维护、AI 输出质量控制、异步任务排查、用户隐私请求处理和基础系统管理。第一版不做复杂数据看板，不做完整审核平台，不做复杂权限系统。

## 设计原则

### 后台效率优先

管理端是内部操作工具，不是面向用户的顾问体验。UI 应清晰、克制、信息密度适中，优先支持运营人员快速完成任务。

视觉方向：

- 使用后台工具风格。
- 使用稳定的左侧导航和顶部状态区域。
- 使用表格、筛选器、详情侧栏、状态标签和版本记录。
- 避免营销化、情绪化和大面积装饰。

### 功能分区清晰

第一版管理端采用功能分区型信息架构，而不是工作流型或 AI 质量中心型。

功能域清晰后，工作台负责聚合待办和异常。

### 控制风险，不扩大范围

第一版不做独立审核模块。必要复核能力分散到对应模块中：

- 风格库发布前状态流转在 `风格库` 内完成。
- AI 异常输出和版本测试在 `AI 配置` 或 `任务` 内查看。
- 用户删除请求在 `用户` 内处理。
- 图片异常先只记录状态，不做独立审核工作台。

## 全局信息架构

一级导航：

```text
工作台 / 风格库 / AI 配置 / 任务 / 用户 / 系统
```

### 工作台

展示运营待办、异常任务、关键状态和最近操作。

### 风格库

维护明星/参考对象、风格样本、标签、可迁移元素和不可迁移风险。

### AI 配置

维护 Prompt、模型配置、报告模板、推荐规则和版本发布。

### 任务

查看异步任务和 AI 任务状态，处理失败、重试和异常排查。

### 用户

支持用户查询、只读摘要查看、删除请求处理和问题排查。

### 系统

维护管理员账号、粗粒度角色和操作日志。

## 工作台

工作台首屏优先展示运营待办。

### 页面目标

- 让运营人员知道今天要处理什么。
- 快速进入风格库发布、失败任务、用户删除请求等操作。
- 轻量展示 AI 质量状态和业务概览。

### 首屏结构

顶部状态：

- 今日待办总数。
- 待发布风格样本。
- 失败任务。
- 用户删除请求。
- 异常 AI 输出。

主内容：

- 待审核或待发布风格样本。
- 失败和异常任务。
- 用户删除请求。
- 近期关键异常。

右侧辅助：

- AI 质量状态摘要。
- 当前 Prompt/模板版本。
- 最近发布记录。

下方：

- 最近操作日志。
- 轻量业务概览，例如报告生成数、建议生成数、反馈数。

第一版不做复杂数据分析看板。

## 风格库

风格库采用对象 + 样本详情型布局。

### 页面目标

- 管理明星或参考对象。
- 维护风格样本结构化知识。
- 保证样本发布前质量。
- 明确可迁移元素和不可迁移风险。

### 页面结构

推荐三栏或主从布局：

1. 左侧：明星/参考对象列表、分组和筛选。
2. 中间：选中对象下的风格样本列表。
3. 右侧或详情页：样本结构化编辑。

### 参考对象

参考对象字段：

- 名称。
- 类型：明星、博主、用户上传参考、内部样本。
- 性别或风格适用范围。
- 标签。
- 状态。
- 备注。

第一版不自动抓取互联网图片。

### 风格样本

风格样本字段：

- 样本名称。
- 关联参考对象。
- 风格标签。
- 适合场景。
- 单品结构。
- 色彩逻辑。
- 发型妆容要点。
- 可迁移元素。
- 不可迁移风险。
- 样本图或参考图。
- 发布状态。
- 维护人。
- 更新时间。

### 状态流转

风格样本状态：

- 草稿。
- 待发布。
- 已发布。
- 已下线。

发布前必须检查：

- 是否存在风格标签。
- 是否填写可迁移元素。
- 是否填写不可迁移风险。
- 是否避免“相貌相似”表达。
- 是否符合明星风格库约束。

### 表达边界

风格库是造型逻辑知识库，不是相貌对比库。

管理端中也应避免将核心字段命名为“像谁”“相似明星”等。推荐使用：

- 参考对象。
- 造型逻辑。
- 可迁移元素。
- 不可迁移风险。

## AI 配置

AI 配置采用版本管理型。

### 页面目标

- 管理 Prompt、模型配置、报告模板、推荐规则。
- 支持草稿、测试、发布和回滚。
- 避免直接修改线上配置。
- 保留操作记录和版本记录。

### 页面结构

采用配置列表 + 版本详情布局：

- 左侧：配置类型和配置列表。
- 中间或右侧：选中配置的版本列表。
- 详情区：当前版本内容、测试样本、发布记录、回滚记录。

### 配置类型

第一版配置类型：

- Prompt。
- 报告模板。
- 推荐规则。
- 模型配置。

### 版本状态

配置版本状态：

- 草稿。
- 测试中。
- 已发布。
- 已下线。

已发布版本不可直接编辑，只能复制为新草稿。

### 详情 Tab

详情页包含：

- 内容。
- 测试样本。
- 发布记录。
- 回滚记录。

### 操作

支持操作：

- 新建草稿。
- 复制为草稿。
- 编辑草稿。
- 运行测试。
- 发布。
- 下线。
- 回滚。

发布、下线和回滚必须二次确认，并写入操作日志。

### 非目标

第一版不做完整 A/B 实验平台，不做批量离线评测系统，不做复杂效果归因。

## 任务

任务页采用全量任务监控，但默认关注失败和异常。

### 页面目标

- 查看异步任务全链路状态。
- 快速定位失败原因。
- 支持重试和排查。
- 关联用户、报告、图片、AI 调用记录。

### 顶部状态

展示：

- 运行中。
- 成功。
- 失败。
- 待重试。
- 已取消。

默认筛选失败和异常任务。

### 任务列表

列表字段：

- 任务 ID。
- 任务类型。
- 状态。
- 关联用户。
- 关联对象。
- 创建时间。
- 更新时间。
- 耗时。
- 重试次数。
- 错误摘要。

支持筛选：

- 任务类型。
- 状态。
- 时间。
- 关联用户。
- 关联资源。

### 任务类型

第一版任务类型：

- 图片视觉识别。
- 衣橱单品结构化抽取。
- 用户画像结构化抽取。
- 参考图风格解析。
- 初版报告生成。
- 每日建议生成。
- 七牛云资源清理。

### 详情侧栏

详情侧栏展示：

- 输入摘要。
- 输出摘要。
- 错误原因。
- 重试次数。
- 关联对象。
- AI 调用记录。
- 任务日志。

### 操作

支持：

- 重试。
- 取消。
- 标记忽略。
- 查看关联用户。
- 查看关联报告。
- 查看关联资源。

高风险操作需要二次确认。

## 用户

用户页采用运营支持范围。

### 页面目标

- 支持用户查询和问题排查。
- 支持查看只读摘要。
- 支持处理删除请求。
- 避免管理员随意修改用户画像、衣橱和记忆。

### 用户列表

列表字段：

- 用户 ID。
- 微信标识摘要。
- 手机号摘要。
- 注册时间。
- 最近活跃时间。
- 报告状态。
- 建议数量。
- 反馈数量。
- 删除请求状态。

支持搜索：

- 用户 ID。
- 手机号摘要。
- 微信标识摘要。

### 用户详情

用户详情展示：

- 基础账号信息。
- 用户画像摘要，只读。
- 衣橱摘要，只读。
- 报告摘要。
- 历史建议摘要。
- 反馈摘要。
- 任务记录。
- 数据删除请求。

### 操作范围

允许操作：

- 处理删除请求。
- 查看关联任务。
- 查看异常记录。
- 必要时禁用账号。

不允许操作：

- 直接修改用户画像。
- 直接修改用户衣橱。
- 直接修改推荐记忆。
- 手动伪造用户反馈。

所有涉及用户数据的查看和操作都要记录操作日志。

## 系统

系统页采用最小系统设置。

### 页面目标

- 管理少量后台账号。
- 使用粗粒度角色控制。
- 查看操作日志。

### 管理员账号

支持：

- 创建管理员。
- 禁用管理员。
- 重置登录信息。
- 分配角色。

### 角色

第一版角色：

- `Admin`：全部管理权限。
- `Operator`：风格库、AI 配置、任务、用户运营能力。
- `Viewer`：只读查看。

第一版不做菜单级、按钮级、数据级复杂权限。

### 操作日志

操作日志记录：

- 操作人。
- 操作时间。
- 操作模块。
- 操作对象。
- 操作类型。
- 操作结果。
- 关键信息摘要。

重点记录：

- 风格样本发布和下线。
- AI 配置发布、下线和回滚。
- 任务重试和取消。
- 用户数据查看。
- 用户删除请求处理。
- 管理员账号变更。

## 非目标

管理端第一版不做：

- 独立审核模块。
- 复杂 BI 数据看板。
- 完整 A/B 实验平台。
- 批量离线评测系统。
- 复杂权限系统。
- 管理员直接修改用户画像、衣橱和记忆。
- 自动抓取公开明星图片。

## MVP 验收标准

管理端 UI 设计满足第一版开发条件，当且仅当：

- 一级导航为 `工作台 / 风格库 / AI 配置 / 任务 / 用户 / 系统`。
- 工作台首屏展示运营待办。
- 风格库采用对象 + 样本详情型布局。
- 风格库样本包含可迁移元素和不可迁移风险。
- AI 配置采用版本管理型。
- AI 配置支持草稿、测试、发布、下线和回滚。
- 第一版不做独立审核模块。
- 任务页支持全量任务监控，并默认关注失败和异常。
- 用户页只做运营支持，不允许直接修改用户画像、衣橱和记忆。
- 系统页只做管理员、粗粒度角色和操作日志。
