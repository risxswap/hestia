# 衣橱单品弹窗编辑设计

## 背景

核心衣橱页面当前在页面中直接展开新增/编辑表单。表单字段较多，会把已有单品和建议补齐内容向下推，新增衣服时的操作焦点不够集中。

## 目标

点击“新增”或“编辑”单品时，使用弹窗式操作区承载当前表单，保持核心衣橱页面作为列表和记忆概览。

## 设计

- 使用自定义小程序 WXML/WXSS 弹窗，不引入新的组件库。
- 弹窗采用底部抽屉形态，适合移动端较长表单。
- 弹窗标题根据状态显示“新增单品”或“编辑单品”。
- 表单字段、推荐状态、核心单品开关、保存和删除逻辑沿用现有实现。
- 弹窗内容区可滚动，底部操作区固定在弹窗内。
- 提供“取消”关闭入口；关闭时清空草稿、退出编辑状态。

## 非目标

- 不新增后端字段。
- 不改衣橱推荐上下文逻辑。
- 不扩展为完整衣橱库存系统。
- 不引入商品链接或电商导购能力。

## 验证

- 更新小程序 API 集成验证，覆盖弹窗结构、关闭 handler 和关闭后的草稿清理。
- 运行小程序相关验证命令，确保衣橱页现有新增、编辑、删除流程不回退。
